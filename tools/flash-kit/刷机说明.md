# Sony GPS Logger v4.9.3 刷机说明

## 文件
- `sony-gps-logger-4.9.3.bin` — 单文件固件（从 0x0 写入）

## 前置
1. 安装 Python 3
2. 安装 esptool：`python3 -m pip install esptool`（Windows：`python -m pip install esptool`）
3. 用 USB-C 连接 M5StickS3

## 刷机
### macOS / Linux
```bash
./flash-macos.sh              # 自动找串口
./flash-macos.sh /dev/cu.usbmodem2101   # 或手动指定
```
### Windows
双击 `flash-windows.bat`，或：
```bat
flash-windows.bat COM3
```

## 重要说明
- 单文件是从 0x0 整片写入，**会清空 NVS**：已保存的相机配对会丢失，需要在
  设备上重新「添加设备」；GPX 轨迹和设置文件保存在 LittleFS 分区，不受影响。
- 想保留相机配对时，请改用分区刷机（bootloader 0x0 / partitions 0x8000 /
  firmware 0x10000），见仓库 README。
